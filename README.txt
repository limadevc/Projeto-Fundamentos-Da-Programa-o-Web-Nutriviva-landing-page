PROJETO: NUTRIVIVA - LANDING PAGE PARA PROFISSIONAL AUTÔNOMA

Disciplina: Fundamentos de Programação Web

Conteúdo do projeto:
- index.html: estrutura completa da landing page.
- css/style.css: estilos, Flexbox e regras de responsividade.
- img/hero-nutricionista.png: imagem utilizada na página.
- documentacao/prototipo.pdf: protótipo para desktop e celular.

Como visualizar:
Abra o arquivo index.html em qualquer navegador atualizado.

Recursos implementados:
- HTML e CSS puros.
- Uso de Flexbox na navegação, nas colunas, nos cards e no formulário.
- Sete faixas de conteúdo, incluindo serviços, benefícios e contato.
- Formulário com campos obrigatórios e tipos apropriados.
- Adaptação para computadores, tablets e celulares.
- Navegação interna entre as seções da página.
